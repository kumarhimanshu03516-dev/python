# Why Python?

Python is a **high‑level, interpreted, general‑purpose language** that emphasises readability and a **batteries‑included** standard library.

## Key strengths

| Area | Why it matters |
|------|----------------|
| **Readable syntax** | Close to English; reduces cognitive load. |
| **Huge ecosystem** | >400 k packages on PyPI (data science, web, automation, …). |
| **Cross‑platform** | Runs on Windows, macOS, Linux, even micro‑controllers (MicroPython). |
| **Strong community** | Conferences (PyCon), countless tutorials, long‑term support (LTS) releases. |
| **Gradual typing** | Optional type hints + static analysis (mypy, pyright) for large codebases. |

## Typical use‑cases

* **Scripting & automation** – replace shell scripts.
* **Data science / ML** – NumPy, pandas, scikit‑learn, PyTorch, TensorFlow.
* **Web back‑ends** – FastAPI, Django, Flask, Starlette.
* **DevOps & tooling** – Ansible, Terraform providers, CI scripts.
* **Education** – First language in many CS curricula.
